# VRCFNetLWDetector

VRChatおよびDiscordの通信障害、そして特定ワールドのアップデートを監視し、Discordチャンネルに自動で通知する軽量Botです。

VRChat公式APIに負荷をかけないよう、極めて安全な設計（5分間隔のチェック、5秒の待機時間）で作られています。個人のサーバー（セルフホスト）で手軽に動かすことができます。

## ✨ 主な機能

*   **🌐 サーバー障害アラート**
    *   VRChatおよびDiscordの公式ステータスを監視し、障害発生時および復旧時に自動で通知します。
*   **🎉 ワールド更新通知**
    *   指定したVRChatのワールド（最大10〜25個程度を推奨）の最終更新日時を監視し、アップデートがあった際にDiscordへ通知します。
    *   時間は見やすい日本時間（JST）に自動変換されます。
*   **🕊️ サーバー負荷軽減設計**
    *   BANリスクを無くすため、APIアクセスは「5分間に1回」「1ワールドごとに5秒の待機」を厳守する安全設計です。

## 🛠 動作環境

*   Python 3.8 以上
*   `discord.py`
*   `aiohttp`

## 🚀 導入手順（セットアップ）

### 1. 必要なライブラリのインストール

コマンドプロンプト（またはターミナル）で以下のコマンドを実行し、必要なライブラリをインストールします。

```bash
pip install discord.py aiohttp
```

### 2. Botトークンの取得と設定

1. Discord Developer Portal にアクセスし、新しいアプリケーションを作成します。

2. 「Bot」メニューからトークンを発行し、コピーします。

3. bot.py をテキストエディタで開き、BOT_TOKEN の部分にコピーしたトークンを貼り付けます。

```python
BOT_TOKEN = 'ここにコピーしたトークンを貼り付けてください'
```

### 3. 監視したいワールドの設定

bot.py 内の AVAILABLE_WORLDS を編集し、通知を受け取りたいワールドの名前とIDを設定します。
（ワールドIDはブラウザでVRChatのワールドページを開いた際のURL wrld_... から取得できます）

```python
AVAILABLE_WORLDS = {
    "ワールドの分かりやすい名前1": "wrld_xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx",
    "ワールドの分かりやすい名前2": "wrld_yyyyyyyy-yyyy-yyyy-yyyy-yyyyyyyyyyyy"
}
```

※注意：VRChatのAPI制限を避けるため、登録するワールド数は**10個以内**に留めてください。

### 4. Botの招待と起動

1. Developer Portalの「OAuth2」>「URL Generator」から、bot と applications.commands にチェックを入れます。

2. 権限として Send Messages と Embed Links にチェックを入れ、生成されたURLから自身のDiscordサーバーにBotを招待します。

3. 以下のコマンドでBotを起動します。


```
python main.py
```

### 💬 コマンド一覧（Discord上での操作）

Botを起動後、Discordのチャット欄で以下のスラッシュコマンドを入力して初期設定を行ってください。（※荒らし防止のため、サーバー管理者のみ実行可能です）

- ``/set_vrchat`` : このチャンネルをVRChat障害の通知先に設定します。

- ``/set_discord`` : このチャンネルをDiscord障害の通知先に設定します。

- ``/set_world`` : リストからワールドを選んで、更新通知先に設定します。

- ``/alert_world`` : 設定したワールド通知の追加・削除を行います。

- ``/remove_alert`` : このチャンネルの通知設定をすべて解除します。

- ``/world_status`` : 現在登録されているワールドの更新状況を手動でキャッシュの部分から確認します（このコマンドは誰でも使用可能です）。

### ⚠️ 開発者向け注意事項

- APIアクセス間隔について
コード内の asyncio.sleep(5)（5秒待機）および @tasks.loop(minutes=5)（5分ループ）は、VRChat公式への過剰なアクセス（サーバー負荷）を防ぐための重要な安全装置です。数値を小さくして頻度を上げると、VRChat側からアクセスを遮断（BAN）される危険性があるため、絶対に短くしないでください。

- 非公式ツールです
本BotはVRChat公式が提供するものではありません。APIの仕様変更等により、予告なく動作しなくなる可能性があります。
